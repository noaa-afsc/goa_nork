"Using SSC accepted model m22.1 from 2022 as the base model for 2024."

There were three model changes explored (in addition to the base 2022 model)
base_srv_like_update - changed the survey likelihood to have a lognormal error structure
base_srv_like_iss - the input sample size for survey age comp data (whe run with 2024 data it is named m22.1b)
m22.1 = m22.1 updated with 2024 data
m22.1a = updated likelihood, using 2024 data
m22.1b = updated input sample size using 2024 data
m24 is the RTMB version of m22.1b, that uses VAST estimated survey biomass with a lognormal error structure *Preferred model*
